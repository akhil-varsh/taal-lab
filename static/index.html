03 / PREDICT THE NEXT BOL

10 probabilities

DhaDhinTinTaNaGeKaTiTeRest

A dense layer produces scores. Softmax converts them into a probability distribution.

RECURRENT STEP hₜ = tanh(Wₓxₜ + Wₕhₜ₋₁ + bₕ)NEXT-BOL PREDICTION pₜ = softmax(Wᵧhₜ + bᵧ)

Implemented in Python with explicit gradients. The studio uses this Elman RNN; the separate Keras experiments include an LSTM variant.

One model. Two different journeys.

  1. 01

    Set the direction

    Choose the taal, cycle count, temperature, and random seed. Tempo determines playback timing.

    YOUR CREATIVE INPUT
  2. 02

    Run a recurrent step

    Encode the previous bol, taal, and beat phase. Combine them with the network’s memory.

    CONTEXT → HIDDEN STATE
  3. 03

    Sample the next bol

    Apply temperature to the scores, then softmax. Sample a bol using the seeded random generator.

    PROBABILITIES → CHOICE
  4. 04

    Feed it back

    Use the chosen bol as the next input. Carry memory across beats and cycles until the phrase is complete.

    AUTOREGRESSIVE GENERATION
  5. 05

    Turn it into sound

    Render synthesized strokes at the selected BPM. The audio clock drives the live wheel and beat highlights.

    LISTEN · LOOP · EXPORT

Musical structure: Cycle length is set by your selected taal. The optional Dha anchor is an explicit rule; an opening phrase takes precedence.

Export routes: WAV contains synthesized percussion, MIDI uses General MIDI approximations, ABC maps bols to symbolic pitches, and JSON preserves the sequence and settings.

  1. 01

    Prepare the corpus

    The bundled corpus has 36 unique cycles across three taals. Split complete phrases into 27 training and 9 validation examples.

    ONE BOL PER BEAT
  2. 02

    Initialize & predict

    Start with Xavier / Glorot uniform weights. Use teacher forcing: the true previous bol is the input during training.

    RESET MEMORY PER PHRASE
  3. 03

    Measure & backpropagate

    Average next-bol cross-entropy over a phrase. Backpropagation through time carries gradients through every recurrent step.

    FULL-PHRASE BPTT
  4. 04

    Update the weights

    Clip global gradient norm at 1.0. Apply one optimizer update per phrase; reshuffle training phrases each epoch.

    DEFAULT: ADAM · LR 0.01
  5. 05

    Keep the best checkpoint

    Evaluate held-out phrases each epoch. Finish the configured run, then retain the weights with the lowest validation loss.

    DEFAULT RUN: 35 EPOCHS

Training choices: Model Lab supports Adam, SGD, SGD with momentum, and RMSprop. Learning rate, epoch count, and random seed are configurable.

What validation tells us: Complete phrases are held out, but rhythmic motifs overlap. This small corpus supports a learning demonstration; musical quality still needs listening and expert evaluation.

From a teaching model to a Keras experiment

The studio runs an explicit Python Elman RNN. The included coursework/keras_experiments.py adds LSTM, deep MLP, autoencoder, CBOW, Skip-gram and MNIST experiments. Use coursework/colab.ipynb to run them with TensorFlow.

THE DATASET

Good rhythms start with context.

A transparent, inspectable corpus for learning sequence models.

36 original teaching phrases27 training · 9 validation · 10 bol tokens

Each first phrase is a familiar theka reference. The remaining phrases are project-authored variations, not expert-annotated performances. One token equals one matra; ornamentation and subdivisions are outside this demo.

Bring your own corpus

Copy data/corpus.json, add unique complete cycles using the supported vocabulary, then run:

python train.py --corpus my_corpus.json --epochs 60

Restart the server to load a model trained from the command line. The Dataset page always displays the bundled corpus. See docs/PROJECT_REPORT.md for provenance, limitations, and evaluation.
